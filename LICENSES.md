# Лицензии используемых технологий

Все ключевые зависимости распространяются под пермиссивными лицензиями
(MIT / BSD / Apache-2.0), разрешающими свободное коммерческое использование,
что соответствует требованию соревнования.

| Технология | Назначение | Лицензия |
|---|---|---|
| Python 3.12 | язык исполнения | PSF |
| LightGBM | ML-фильтр сигналов (buy / short) | MIT |
| scikit-learn | метрики и утилиты ML | BSD-3-Clause |
| numpy | численные операции | BSD-3-Clause |
| pandas | обработка данных (offline-обучение) | BSD-3-Clause |
| requests | HTTP-клиент (ArenaGo, Polza) | Apache-2.0 |
| python-dotenv | загрузка конфигурации | BSD-3-Clause |
| moexalgo | рыночные данные MOEX / ALGOPACK | MIT |
| joblib | сериализация ML-моделей | BSD-3-Clause |

## Внешние сервисы (не библиотеки)

- **ArenaGo** — торговая площадка соревнования (execution + портфель). Доступ по
  ключу `SANDBOX_API_KEY`, выдаётся организаторами.
- **MOEX / ALGOPACK** — источник рыночных данных по официальному токену
  `MOEX_ALGO_TOKEN`.
- **Polza.ai** — агрегатор LLM. Используются только открытые модели со свободной
  коммерческой лицензией: DeepSeek (V4 Flash/Pro, MIT) и Qwen3 (Apache-2.0) — для
  контекстного/объясняющего слоя. LLM **не принимает финальное торговое
  решение** — только классифицирует режим рынка, объясняет сделки и подстраивает
  параметры в заданных границах. Используется как сервис по API-ключу, веса
  моделей не модифицируются.

## Обученные модели (воспроизводимость)

`data/models/lgbm_buy_filter_v4.joblib` и `lgbm_short_filter_v1.joblib` обучены
нами на исторических данных MOEX/ALGOPACK (2023–2026). Скрипты обучения,
параметры и метаданные (`*.meta.json`) лежат в репозитории
(`src/moex_agent/ml_baseline.py`, `ml_offline_dataset.py`) — результат
воспроизводим.
