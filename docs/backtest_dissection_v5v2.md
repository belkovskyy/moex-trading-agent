# Вскрытие −38.2%: декомпозиция бэктеста v5+short_v2 (20 бумаг, 2023–2026)

2026-08-19. Источники: data/backtests/v5v2_noscalein_20260819_061855.json,
v4v1_noscalein_20260819_062732.json, x_ml_both.json. Полного трейд-лога на момент разбора не было,
поэтому часть выводов сделана на агрегатах и сэмпле последних 100 сделок — такие места помечены.
Уточнённые числа по полному дампу — в calibration_verdict.md.

## 1. Главное: убыток — это в основном издержки, а не стратегия

Оборот за 3.5 года: 471.4 млн ₽ при капитале 1 млн и средней позиции 12.6 тыс ₽.
~19 сделок в день, средняя дистанция сделки +0.32% при цене круга 10–20 б.п.

Декомпозиция −382.4 тыс ₽ (сверка equity против суммы pnl_rub по бумагам):

| Компонент | ₽ | Комментарий |
|---|---|---|
| Реализованный PnL (в ценах с проскальзыванием) | −264.5 тыс | сумма per_symbol |
| Комиссия (гэп equity − realized) | −117.8 тыс | ровно 2.5 б.п. × оборот |
| Проскальзывание, зашитое в цены | −117.8…−235.7 тыс | 5 б.п. на круг или на сторону — уточнить по коду |
| **Итого издержки** | **−235.7…−353.5 тыс** | **62–92% всего убытка** |
| **Стратегия без издержек (gross)** | **−28.8…−146.7 тыс** | **−2.9%…−14.7% за 3.5 года** |

Вывод: gross-результат стратегии — около нуля или умеренный минус; в −38% его превращает
частота торговли. Главный рычаг — оборот, а не отбор входов.
ТРЕБУЕТ ПОДТВЕРЖДЕНИЯ ПО КОДУ: slippage_bps и commission_bps — на сторону или на круг.

## 2. Win rate 70% — артефакт учёта выходов

Записи в логе — ВЫХОДЫ, не позиции. На сэмпле последних 100 записей: 100 выходов = 72 позиции,
28 позиций закрывались частями. Win rate на уровне выходов 66%, на уровне позиций 52.8%,
средний PnL позиции −2.6 ₽. Реальные метрики системы надо считать по позициям.

## 3. Асимметрия размеров есть и без докупок

Из агрегатов (точно, не сэмпл): лонги — средний выигрышный выход при размере 8.7 тыс ₽,
средний убыточный при 22.0 тыс ₽, **отношение 2.55×** при отключённом scale-in.
Шорты симметричны (1.10×). Механизм (по сэмплу): выигрыши забираются частями/на частичном
размере (overbought/reversal — средний размер выхода 9.0 тыс), стоп бьёт по полному
остатку (стоп-выходы — 17.0 тыс). Плюс time_exit_hours=0: средняя длительность 19.7 ч,
позиции регулярно ночуют (стоп 1.2% не защищает через гэп: средний убыток −1.42%).

## 4. Утечка равномерна по времени и по бумагам

По годам (v5v2): 2023 −93.2К, 2024 −128.6К, 2025 −108.1К, 2026H1 −51.5К. Ни одного
плюсового года, катастрофических событий нет — постоянный дренаж. Kill-switch −8%,
который стоит в конфиге live, в бэктесте не применяется: порог был бы пробит 16.11.2023 —
живая система остановилась бы там навсегда.

По бумагам: 15 из 20 в минусе по ₽, при этом avg_pnl_pct положительный у ВСЕХ 20 —
асимметрия размеров универсальна. Худшие: PIKK −41.2К (2168 сделок — самая торгуемая!),
NVTK −37.1К, NLMK −25.7К, GAZP −24.2К. Бот активнее всего торгует бумаги в секулярном
падении — mean-reversion лонги ловят ножи. Около нуля/плюс: LKOH +0.8К, YDEX +1.5К,
X5 +3.1К, SBER −6.5К. Разброс числа сделок по бумагам (SBER 751 против PIKK 2168) —
отдельный вопрос к фильтру.

## 5. Сверка августовских замеров

x_ml_both.json: dataset = ml_dataset_local.jsonl (494 003 строки) → «−0.17%» действительно
получен на узком наборе бумаг. На 20 бумагах картину определяют бумаги, которых

## 6. Что делать (пересобранные приоритеты)

1. **Резать оборот** — главный рычаг, ~62–92% убытка: порог фильтра вверх (свип 0.70/0.75/0.80
   на v5), минимальный ожидаемый ход > 3× цены круга, time-exit (см. майские эксперименты
   v4_t085_timex6h), запрет входа за N баров до конца сессии.
2. **Учёт и выходы на уровне позиций**: метрики по позициям; после частичного выхода —
   стоп в безубыток по остатку; пересмотреть частичные выходы (они создают асимметрию 2.55×).
3. **Трендовый гейт на лонги** (PIKK-эффект): не покупать mean-reversion в бумаге в устойчивом
   даунтренде (например, ниже долгосрочной SMA по дневкам) — regime.py на уровне рынка это
   не ловит, нужен уровень бумаги.
4. Сайзинг по P(up) — вместе с п.1 (порог+размер из одной кривой калибровки).
5. Метка v3 — после пп.1–2: метка должна кодировать УЖЕ ПОЧИНЕННУЮ политику выходов,
   иначе модель выучит исходы дырявой политики.
6. LLM A/B — параллельно, см. ограничения ниже.

## 7. Ограничения для LLM A/B (по мотивам ресерча)

Дизайн валиден только при трёх условиях:
1. **Только вперёд, без реплея истории.** LLM знает 2023–2026 из весов — реплей супервизора
   по прошлым датам даёт скрытый lookahead, ровно тот, за который ресерч ругает чужие Sharpe.
   Пусть медленнее, но честно: форвард на живой бумаге.
2. **Парный дизайн**: оба плеча получают один поток сигналов/котировок, различие только
   в супервизоре; издержки и модель филлов одинаковы (смещение филл-модели сокращается в паре).
   Метрики: дневной paired PnL-diff, drawdown, счётчик вмешательств + counterfactual каждого
   вето (машинка из gates_counterfactual переиспользуется).
3. **Код заморожен на всё окно**, auto_tuner выключен в обоих плечах (тюнер — отдельный
   эксперимент вторым этапом). Стартовать после фиксов оборота: мерить супервизию над ботом,
   который сжигает 20 б.п. на круг 19 раз в день, — мерить насос с дыркой.
